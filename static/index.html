Perceptron – phân lớp tuyến tính

Quan sát Perceptron cập nhật trọng số để tìm một đường thẳng phân tách hai nhóm điểm.

Giới thiệu

  • Quan sát các điểm thuộc hai lớp khác nhau.
  • Đường phân tách được cập nhật theo từng bước học.
  • API dùng: /api/perceptron.
